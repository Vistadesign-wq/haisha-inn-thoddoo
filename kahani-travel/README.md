# Kahani Travel & Tours website

"Stories in Every Step." This is a one-page site for Kahani Travel & Tours, Thamarassery, Kozhikode.

- `index.html`: page layout (About, Services, Packages, Attestation, Umrah, Contact)
- `data.js`: **edit here** for the WhatsApp number, social links, services and all packages (itineraries, highlights, photos)
- `script.js`: slideshow, package tabs and pop-up, WhatsApp/email enquiry forms
- `style.css`: design (brand navy #384770, teal #1f9d8b, orange #f0601c)
- `assets/`: logo, office photo and posters

Destination photos load from Unsplash. Open `index.html` in a browser, or host the folder on GitHub Pages or any web host.
